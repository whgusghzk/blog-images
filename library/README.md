# Photo library

Drop your own photos here (JPG/PNG). The daily post task uses them as cover images.

Name files by what's in them, in English, with hyphens, e.g.
`seoul-subway-gate.jpg`, `tmoney-card.jpg`, `myeongdong-street-night.jpg`, `bank-atm.jpg`.

Tips
- Landscape (horizontal) photos work best; they're cropped to 16:9.
- No faces of strangers, license plates, or documents with personal info.
- Each photo is used at most once every couple of weeks.
